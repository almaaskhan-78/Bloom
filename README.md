# 🌸 Bloom

### A little progress every day.

Bloom is a personal productivity desktop app that I created **for myself**.

I wanted one simple place where I could keep track of the things I’m learning, projects I’m working on, tasks I need to finish, certificates I want to complete, and notes I want to keep — without having everything scattered across different apps and notebooks.

So instead of looking for the perfect productivity app, I decided to **build my own.** 🌱

## ✨ What Bloom Helps Me Organize

* ✅ Everyday tasks
* 📚 Skills I'm learning and my progress
* 🚀 Projects I'm working on
* 🎓 Certificates I want to complete
* 📝 Personal and study notes
* 📊 My overall progress

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🎨 Why I Built It

Bloom started as a small idea: **turn my own goals and progress into something I could actually see.**

I wanted the app to feel personal, simple, and a little playful rather than like another complicated productivity tool.

The project also gives me a space to learn by building. Every feature gives me an opportunity to practice web development, UI design, JavaScript, problem-solving, and debugging.

## 🌱 What I'm Learning Through Bloom

* Building multi-page applications
* Connecting different pages and features
* Working with HTML, CSS, and JavaScript
* Creating interactive UI elements
* Designing a consistent interface
* Debugging and improving my own code
* Using AI-assisted development while understanding and modifying the code myself

##  Current Status

**Bloom is still a work in progress.**

I'm continuing to add features, improve the interface, and shape it into a productivity app that actually fits the way I work and learn.

> **Bloom is my little digital space for making progress, one step at a time. 🌸**
